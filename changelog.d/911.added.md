Set `logging.ak.level` (or `AK_LOGGING__AK__LEVEL`) to the new `TRACE` level, below `DEBUG`, to log one timestamped line per request stage (`REQUEST_RECEIVED`, `INPUT_ENQUEUED`, `AGENT_START`, `RESPONSE_DELIVERED` and so on) in queue mode, on AWS serverless and on AWS ECS, for benchmarking where a request spends its time. `agentkernel.core.TraceLine.parse` reads those lines back, including from CloudWatch logs. See [Configuration](https://kernel.yaala.ai/docs/core-concepts/configuration).
