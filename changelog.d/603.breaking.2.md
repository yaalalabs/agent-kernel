Queue mode: the process that accepts a chat request now answers 404 or 403 itself, before anything is queued, for an agent its registry does not know or the caller may not use; a process whose registry knows no agent at all still queues every request. To migrate a split deployment whose accepting process loads only some of the agent modules, share the registry (`registry.type`) or load the same modules in both processes; see [Queue mode](https://kernel.yaala.ai/docs/advanced/queue-mode-guide).
