For code that extends OAK: `ChatService.execute*` and `ChatService.prepare_agent_handler` raise `AgentNotFoundError` (a `LookupError`) for an unknown agent where they raised `ValueError`, `AgentRESTRequestHandler.list_agents` takes the request as its first parameter, and the queue pipeline's chat route no longer calls `RequestHandler.enqueue_and_wait`. To migrate, catch `AgentNotFoundError`, accept `request` in a `list_agents` override, override `RequestHandler.run_chat` to change the pipeline chat route, and accept an optional `surface` argument in overrides of `AgentService.select`, `AgentHandler.initialize`, `ChatService.prepare_agent_handler` and `ScheduleManager.create`.
