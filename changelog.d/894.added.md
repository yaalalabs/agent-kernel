SSE streaming on the AWS Lambda serverless deployment: `execution.mode: rest_sync` with `message_type: delta` now streams the reply as `data:` frames. The request-handler Lambda serves the app with `agentkernel.aws.LambdaStreamServer` behind the AWS Lambda Web Adapter. Terraform: with `execution_mode = "rest_sync"` and `message_type = "delta"`, the serverless module switches the request-handler integrations to response streaming, and `terraform plan` refuses the pair without `queue_mode`, with standard queues, with the DynamoDB response store, or with an `authorizer` (use the app's `identity` block instead). See [SSE Streaming on AWS Serverless](https://kernel.yaala.ai/docs/deployment/aws-serverless#sse-streaming-rest_sync--delta).
