The examples now use `gpt-6-luna` with reasoning turned off in place of `gpt-4.1-mini`, which OpenAI is retiring: each agent sets its framework's own switch (`reasoning_effort="none"` for ADK, LangChain, CrewAI and smolagents, `ModelSettings` for the OpenAI Agents SDK and Pydantic AI, `default_options` for Microsoft Agent Framework), so replies come back without a thinking step. Copy the setting when you point your own agents at a reasoning model.
