ECS queue mode now runs the shared pipeline classes, and the ECS-only ones are removed: `ECSAgentRunner`, `ECSStreamAgentRunner`, `ECSRealtimeAgentRunner`, `ECSOutputConsumer`, `ECSIOHandler`, `AWSRestAPI` and `ECSQueueRequestHandler`. To migrate, start the agent runner with `agentkernel.pipeline.AgentRunner.run()`, the REST entry point with `agentkernel.pipeline.IOHandler.run()` and the WebSocket entry point with `AWSWebsocketAPI.run()`, and drop the separate output consumer. See [AWS containerized: scalable queue mode](https://kernel.yaala.ai/docs/deployment/aws-containerized#scalable-queue-mode).
