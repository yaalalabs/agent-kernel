With an `authorization` block, an agent with tools OAK cannot gate no longer loads: a LangGraph agent with a tool not bound through `LangGraphToolBuilder.bind` (a LangChain `@tool`, a `StructuredTool` built by hand, in the graph or a subgraph), a smolagents code agent on a remote executor, and an OpenAI Agents SDK agent with `mcp_servers` or a handoff that does not hold its agent. To migrate, bind LangGraph tools with `LangGraphToolBuilder.bind`, run smolagents code agents on the local executor, and move MCP tools to a framework that lists them. See [Authorization](https://kernel.yaala.ai/docs/advanced/identity-and-access#authorization).
