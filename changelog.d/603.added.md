Add authorization: an `authorization` block grants users, groups, roles and messaging senders a level (`read`, `write` or `admin`) on agents, and with it a caller runs only the agents it is granted and is listed only the ones it may see, on REST, A2A, MCP, AG-UI and realtime calls. A tool policy (`tiers`, `allow`, `deny`) narrows the tools the agent catalog and A2A cards list for a caller, and keeps a denied tool from the model on the OpenAI Agents SDK, Pydantic AI, Microsoft Agent Framework and the Claude Agent SDK; on Google ADK, CrewAI, LangGraph and smolagents, and on realtime calls a denied tool is not stopped yet. See [Authorization](https://kernel.yaala.ai/docs/advanced/identity-and-access#authorization).
