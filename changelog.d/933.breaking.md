The `mcp` extra now needs FastMCP 4 (`mcp>=2.3`), so `agentkernel[crewai]` and `agentkernel[mcp]` can no longer be installed together: CrewAI pins `mcp<2`. To migrate, install them in separate environments, and in `fastmcp.Client` code on the 2026-07-28 protocol replace `ping()` with `list_tools()` and pass `httpx2` objects where `httpx` ones were passed. See [Installation](https://kernel.yaala.ai/docs/installation#dependency-conflicts).
