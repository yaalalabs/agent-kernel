The `mcp` extra now needs FastMCP 4 (`mcp>=2.3`), so `agentkernel[crewai]` and `agentkernel[mcp]` can no longer be installed together (CrewAI pins `mcp<2`); to serve a CrewAI agent over MCP, run a split deployment as described in [Installation](https://kernel.yaala.ai/docs/installation#dependency-conflicts). Tools you register on `MCP.get()` now run on FastMCP 4: import `ToolResult` from `fastmcp.tools`, and log with your own logger instead of `Context.info()` / `debug()`. In `fastmcp.Client` code on the 2026-07-28 protocol, replace `ping()` with `list_tools()` and pass `httpx2` objects where `httpx` ones were passed; see FastMCP's [upgrade guide](https://gofastmcp.com/docs/getting-started/upgrading/from-fastmcp-3).
