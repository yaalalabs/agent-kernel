Terraform: the AWS containerized (ECS) module now serves its non-WebSocket routes through an API Gateway REST API instead of an HTTP API, so that SSE can stream. The API is recreated, so the invoke URL changes. To migrate, re-apply and then re-register every webhook URL held by a messaging platform or client from the new `agent_invoke_url`; deployments that build those URLs from the `api_gateway_id` and `api_gateway_stage` outputs recompute them on re-apply, but a URL registered by hand in a platform console still has to be re-registered. The ALB idle timeout also rises from 60 to 300 seconds, configurable with the new `alb_idle_timeout`. Two further behaviour changes come with the gateway swap: the `cors_allow_*` variables stop having any effect, so a deployment that used `cors_allow_origins` to restrict browser access loses that restriction (the container answers preflight with `allow_origins=["*"]`); and `overwrite_path` no longer accepts `$request.header.<name>`, `$request.querystring.<name>` or a bare `$request.path`, which are now rejected at `terraform plan`. See [Upgrading to the streaming REST gateway](https://kernel.yaala.ai/docs/deployment/aws-containerized#upgrading-to-the-streaming-rest-gateway).
