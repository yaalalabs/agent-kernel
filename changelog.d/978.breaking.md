Terraform: the AWS containerized (ECS) module now serves its non-WebSocket routes through an API Gateway REST API instead of an HTTP API, so that SSE can stream. The API is recreated, so the invoke URL changes. To migrate, re-apply and then re-register every webhook URL held by a messaging platform or client from the new `agent_invoke_url`; deployments that build those URLs from the `api_gateway_id` and `api_gateway_stage` outputs pick up the new values automatically. The ALB idle timeout also rises from 60 to 300 seconds, configurable with the new `alb_idle_timeout`. See [Upgrading to the streaming REST gateway](https://kernel.yaala.ai/docs/deployment/aws-containerized#upgrading-to-the-streaming-rest-gateway).
