The agent catalog and A2A cards list more exactly what an agent can call. An agent now also lists the tools of the agents a run of it can reach: the agents an OpenAI Agents SDK agent hands off to or uses as tools, the agents a Google ADK agent uses as tools and the nodes of a nested workflow, and the coworkers of a CrewAI agent that may delegate. A Pydantic AI tool behind a prefixed or renamed toolset, and a callable object on a Google ADK agent, are listed under the name the model calls them by.
