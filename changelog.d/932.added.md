Serve A2A and MCP from the AWS Lambda (serverless) deployment in queue mode (`rest_sync` and `rest_async`): build a `LambdaProtocolHost` in the request-handler Lambda, register its `handle` for `ProtocolPaths.ROUTES` (both exported from `agentkernel.aws`), and turn on the new `enable_a2a_server` and `enable_mcp_server` inputs of the `ak-serverless` Terraform module (off by default). A setup that cannot serve them (no SQS transport, `async` mode, stateful MCP, or a reply wait longer than API Gateway's 29 s) fails the Lambda's cold start with the setting to fix. See [A2A and MCP on Lambda](https://kernel.yaala.ai/docs/deployment/aws-serverless#a2a-and-mcp-on-lambda).
