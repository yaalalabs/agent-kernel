The OpenAI guardrails work with the default `gpt-6-luna` guardrail model: the model call that carries a check asked for a 1-token reply, which `gpt-6-luna` rejects with "Could not finish the message", so every harmless prompt came back as "unable to process your request". It now asks for 16 tokens and turns reasoning off for reasoning models. OpenAI Agents SDK agents no longer return an empty reply now and then on `gpt-6-luna`: the model can write its answer as a "commentary" message and close with a blank "final answer", and the reply is now taken from that last non-blank message.
