A benchmark harness, `ak-bench`, in the repository's `benchmarks/` folder. It deploys an Agent Kernel app, sends steady or burst load to it in steps over WebSocket, and records per-request latency by request stage, throughput, scaling, resource usage and cost as CSVs and graphs. No built-in host ships yet; see the [ak-bench README](https://github.com/yaalalabs/agent-kernel/blob/develop/benchmarks/README.md).
